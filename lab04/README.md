### Задание 1 **(3)**
* *Запишите двоичное представление числа -99 в целочисленном знаковом типе длиной 1, 2, 4 байта.* 
* *Запишите литералы равные наибольшему и наименьшему числу в типе* **int** *в шестнадцатеричной записи.*
* *Запишите двоичное представление символа "`#`" в типе* **char**.

#### Ответ:
##### 1. Число -99 (дополнительный код)

Отрицательные числа в памяти хранятся в дополнительном коде. 
Для начала берем положительное 99: `01100011`, инвертируем биты: `10011100`, после этого прибавляем 1: `10011101`.

При увеличении размера до 2 и 4 байт слева добавляются единицы.

**1 байт:** `10011101`

**2 байта:** `11111111 10011101`

**4 байта:** `11111111 11111111 11111111 10011101`

##### 2. Границы типа `int` (32 бита)

Стандартный `int` занимает 32 бита, где самый первый бит - знаковый (`0` для плюса, `1` для минуса).

В шестнадцатеричной системе каждые 4 бита превращаются в один символ (от 0 до F).

**Max:** Знаковый бит `0`, остальные 31 бит - `1`. В бинарном виде `0111 1111...`, что в шестнадцатиричной записи дает семерку и кучу F.

**Min:** Знаковый бит `1`, остальные 31 бит - `0`. В бинарном виде `1000 0000...`, что в шестнадцатиричной записи дает восьмерку и нули.

* **Max:** `0x7FFFFFFF`

* **Min:** `0x80000000`

##### 3. Двоичное представление символа `#` в типе char.

В таблице символов ASCII `#` имеет десятичный код 35. 

Переводим 35 в двоичный вид (32 + 2 + 1): получаем `100011`, далее мы просто дополняем его нулями слева до нужного размера типа `char` (8 бит в C++ или 16 бит в Java).

**1 байт (C++):** `00100011`

**2 байта (Java):** `00000000 00100011`

### Задание 2 **(3)**
*Напишите пример программы на С++ с использованием целочисленных литералов в разных форматах записи, 
разной длины, знаковых и беззнаковых. 
Пример должен охватывать большинство способов записи целочисленных литералов.*

```
#include <iostream>

```


### Задание 3 **(2)**
*Объясните работу фрагмента программы на С++. В ходе объяснения следует использовать таблицу кодов символов.*
```
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

#### Ответ:

Используем коды символов ASCII:

- `'a'` = 97 = `0b01100001`;
- `97 + 10 = 107`, а код 107 - это `'k'`;
- затем `107 + 250 = 357`.

В `char` длиной 1 байт значение хранится по модулю 2^8 = 256:

357 mod 256 = 101

Код 101 - символ `'e'`.

Поэтому программа выводит:

```
ke
```

Первый символ появляется из обычного сложения кодов, а второй - после переполнения `char`.

### Задание 4 **(2)**

*Перепишите программу из предыдущего задания на Python, используя функции* **chr** и **ord**.
*Почему ее вывод отличается от вывода программы на С++?*

#### Ответ:

```
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')

a = chr(ord(a) + 250)
print(a, end='')
```

Результат:

```
kť
```

Почему результат отличается от C++:

- в C++ `char` имеет фиксированную разрядность, поэтому после `357` происходит переполнение 8-битного значения: `357 mod 256 = 101`;
- в Python `int` имеет произвольную длину, поэтому значение `357` не переполняется и `chr(357)` возвращает символ с кодом 357 — `ť`.


### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```
#### Ответ: 
Для 16-битного `unsigned short`: `2^16 = 65536`

Сначала: `y = 40000 + 40000 = 80000`

После записи в `unsigned short`: `80000 mod 65536 = 14464`

То же происходит с `z`: `z = 40000 * 2 = 80000`, поэтому `z = 14464`.

Дальше: `y = 14464 - 40000 = -25536`

При записи результата обратно в `unsigned short`: `-25536 mod 65536 = 40000`

А для `z`: `z = 14464 / 2 = 7232`.

Почему `x + x - x = x`, но `(x * 2) / 2 != x`: при первом вычислении после переполнения снова получается `x`, потому что из результата `80000 mod 65536 = 14464` вычитается `40000`, после чего происходит ещё одно приведение по модулю. Во втором случае деление выполняется уже после потери старших разрядов, поэтому исходное значение восстановить нельзя.

### Задание 7 **(2)**

*Напишите программу на Python умножающую введенное число на 1000. В программе 
можно использовать только операторы сдвига и сложения. Циклы использовать нельзя. Из функций
можно использовать только* **input** *и* **print** *для ввода и вывода.*
```
x = int(input())
y = ...
print(y)
```
#### Ответ:

Разложим 1000 по степеням двойки: `1000 = 512 + 256 + 128 + 64 + 32 + 8` или `1000=2^9 + 2^8 + 2^7 + 2^6 + 2^5 + 2^3`

Поэтому:

```
x = int(input())
y = (x << 9) + (x << 8) + (x << 7) + (x << 6) + (x << 5) + (x << 3)
print(y)
```

Каждый сдвиг влево на `k` эквивалентен умножению на `2^k`.
